## Build-out steps

Facebook (must be a Page, not a personal profile, for automated posting later):
1. Open the Munymo Page, click the profile picture, upload `munymo-avatar-1080.png`.
2. Click "Edit cover photo", upload `munymo-facebook-cover-1640x624.png`.
3. "Edit Page info" / "About": paste the intro, the About text, the website and the category.
4. Add the action button.

Instagram (must be a Professional account, type Business, linked to the Facebook Page, for automated posting later):
1. Profile, "Edit profile": upload the avatar, paste the bio, add the website link.
2. Settings, "Account type and tools", "Switch to professional account", choose Business, category Education.
3. When asked, connect it to the Munymo Facebook Page.

## Posting rules (for the automation, not yet built)

- One post per US trading day, only after that game's result is public. Never spoil a live game.
- Each post = a branded result card image + the Hindsight Spotlight as the caption + a link to that game's page (on Instagram: "link in bio").
- Sign the research as Mo's. No hype, no asking for follows, no predictions or recommendations.
